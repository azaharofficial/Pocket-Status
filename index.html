One-time setup (2 minutes):

  1. Open console.cloud.google.com, create a project, and enable the Google Drive API.
  2. Go to Credentials → Create Credentials → OAuth client ID → Web application.
  3. Add your app origin under Authorized JavaScript origins, then copy the Client ID.
  4. Paste the Client ID below — tapping One-Click Sync connects and syncs My Drive / Apps/Pocket Apps/Backups/Pocket Status / pocket-status-backup.json automatically.

Using offline APK / WebView?

You can also paste a Google Apps Script Web App URL (https://script.google.com/macros/s/.../exec) into the field below and tap Connect.
